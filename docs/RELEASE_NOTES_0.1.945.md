# Alternate Commander 0.1.945

Changes since 0.1.944.

## HEIC / JPG conversion works on servers
**Files > Convert HEIC / JPG...** now also takes pictures in a server panel, or in a list of files found on a server. The results can be saved next to the originals on the server, in the folder of the other panel, or on this computer. The pictures are downloaded, converted on this computer and uploaded; existing files are not overwritten.

## Fixed: a search could come back empty because of a filter that was not visible
A new search window now starts without the filters of the **Advanced** tab (dates, size, attributes, duplicates). Before, a filter left over from an earlier search stayed on and was also applied to the search of a server. While a filter is on, the Advanced tab has a dot and the line under the results names it. Saved searches (Load/Save) keep their filters.

## Download and update
The program updates itself (Configuration > Check for Updates). All files are at https://altcom.cc
